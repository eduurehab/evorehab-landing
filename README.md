# EVOREHAB Landing Page

Landing page simple para EVOREHAB, el programa online de readaptación de rodilla de @edu.rehab.

## Objetivo

Esta página está pensada para que una persona que ya ha agendado una llamada pueda ver un vídeo previo y acceder a información clave antes de hablar con nosotros.

## Contenido de la landing

- Vídeo prellamada.
- Botón hacia preguntas frecuentes del servicio.
- Botón hacia casos de éxito y testimonios.

## Tecnologías usadas

- HTML
- CSS
- JavaScript básico

## Publicación

La web se publicará como Static Site en Render usando el enlace gratuito de Render.
